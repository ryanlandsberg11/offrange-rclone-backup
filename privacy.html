Privacy Policy

OFFRANGE Personal Backup is a personal-use configuration of Rclone for backing up files to the owner's Google Drive account.

The application accesses Google Drive only to create, read, and update backup files.

Rclone runs locally on the owner's computer. Authentication tokens are stored locally. Backup files are transferred to Google Drive under the account owner's control.

No Google user data is sold or used for advertising. The application does not operate a separate server to collect user data.

Use of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements.

The owner can revoke Google Drive access through Google Account security settings.
